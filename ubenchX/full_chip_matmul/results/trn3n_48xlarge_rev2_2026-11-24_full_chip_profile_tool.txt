== ./performance_profile_tool -h
Usage: ./performance_profile_tool [--profile <profile>] [--get-profile] [--get-supported-profiles]
  --profile <profile>        : Set performance profile
  --get-profile              : Get current performance profile
  --get-supported-profiles   : Get supported profiles common to all devices
  --set-pcie-profile <n>     : Set PCIe profile (numeric, 0-255) on all devices
  --get-pcie-profile         : Get current PCIe profile from all devices
  --help                     : Show this help

Profiles are platform-specific; the tool detects the platform and accepts
only that platform's profiles.

Trainium2 profiles (string name or numeric index may be used interchangeably):
  2.4ghz_balanced_peak_capability  (numeric: 0)
  2.0ghz_high_peak_capability      (numeric: 1)
  2.0ghz_moderate_peak_capability  (numeric: 2)
  2.4ghz_moderate_peak_capability  (numeric: 3)
  2.4ghz_high_peak_capability      (numeric: 4)
  2.2ghz_balanced_peak_capability  (numeric: 5)
  2.0ghz_balanced_peak_capability  (numeric: 6)
  2.2ghz_moderate_peak_capability  (numeric: 7)
  2.2ghz_high_peak_capability      (numeric: 8)
  7.2ghz_hbm_clock                 (numeric: 9)
  2.4ghz_reduced_peak_capability   (numeric: 10)
  2.4ghz_low_peak_capability       (numeric: 11)

Note: The HBM clock profile (7.2ghz_hbm_clock) is mutually exclusive with the power profiles.

Trainium3 profiles (string name only):
  2.4ghz_tpb_1.2ghz_soc
  2.0ghz_tpb_1.2ghz_soc
  2.2ghz_tpb_1.2ghz_soc
  2.4ghz_tpb_1.1ghz_soc
  2.6ghz_tpb_1.1ghz_soc
  2.4ghz_tpb_1.2ghz_soc_low_peak_capablity
  2.4ghz_tpb_1.2ghz_soc_reduced_peak_capablity
  2.4ghz_tpb_1.2ghz_soc_balanced_peak_capablity
  1.8ghz_tpb_0.9ghz_soc
  2.0ghz_tpb_1.1ghz_soc

Note: On Trainium3, --get-profile and --get-supported-profiles are not yet
supported by the device firmware.
Note: This tool will set/get the profile on ALL available Neuron devices.
