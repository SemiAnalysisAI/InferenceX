## What is patched

| Upstream PR/commit | What it changes | How |
|---|---|---|
| vllm [#66324](https://github.com/vllm-project/vllm/pull/66324), head `7f860cd31` | Adds the opt-in MiniMax-M3.1-Flash specialized decode: CuTe DSL kernels for FULL-graph decode steps of up to 8 requests × (K + 1) rows. ## Why the unmodified upstream image cannot run this benchmark

The specialized decode is not on vLLM `main` yet, so no public `vllm/vllm-openai` image contains it. The PR is pure Python (CuTe DSL is JIT-compiled), so applying it to the newest nightly is the smallest change that measures it.
