# Inference-engine patch waiver — PR #4629

Filed per [`docs/PR_REVIEW_CHECKLIST.md`](../PR_REVIEW_CHECKLIST.md) (image-provenance / patch item): the
setup script of the `infera-sglang` points patches the pinned SGLang image before serving, which the
checklist prohibits unless covered by a filled-out waiver.

  ([`benchmarks/multi_node/srt-slurm-recipes/configs/infera-sglang.sh`](../../benchmarks/multi_node/srt-slurm-recipes/configs/infera-sglang.sh)),

- **Patch script:** [`benchmarks/multi_node/srt-slurm-recipes/configs/infera-sglang-patches/apply.sh`](../../benchmarks/multi_node/srt-slurm-recipes/configs/infera-sglang-patches/apply.sh)

## What is patched

`apply.sh` edits the image's SGLang source in place (`/sgl-workspace/sglang`, the tree the image's
`sglang` package is installed from). Every fix is anchored on the exact source it replaces, is
idempotent, and is checked by a marker afterwards; a fix that does not apply fails the job instead
of serving unpatched.

| | Upstream PR/issue | What it changes | Why this config needs it |
|---|---|---|---|
| B1 | sglang [#33059](https://github.com/sgl-project/sglang/pull/33059) | DSA indexer on HIP: trim the DP-padded query rows before the aiter top-k kernel and restore them after (`layers/attention/dsa/dsa_indexer.py`) | DP-attention decode. On this source the aiter branch passes the padded `q_fp8` whole (`dsa_indexer.py:1366-1376`; the XPU branch slices to `[:q_offset]`) and the restore at `:1438` excludes HIP |
| B2 | sglang [#46830](https://github.com/sgl-project/sglang/pull/46830) | DSA backend: no device-to-host sync on per-rank branches (`layers/attention/dsa_backend.py`) | DP-attention decode with MTP. `seq_lens.max().item()` (`:1102`) and two `.cpu()` calls (`:1172-1179`) sit on branches that only some DP ranks take, so the ranks deadlock in a collective |
| B6 | sglang [#46820](https://github.com/sgl-project/sglang/pull/46820) | Send the per-step `KvMetrics` record with `zmq.NOBLOCK` and drop it when the queue is full (`managers/scheduler_components/kv_events_publisher.py`) | Prefill runs with KV events (the router routes on them). The record is PUSHed blocking (`:89-90`) to an endpoint nothing in SGLang binds; once the queue fills, the scheduler stops |

A middle pipeline stage holds a `PPMissingLayer` (`:2923`), so the reads at `:2987, :3022` raise `AttributeError` at load |
| B8 | sglang issue [#46829](https://github.com/sgl-project/sglang/issues/46829) | Drop the hand-written Triton tile config of the MLA absorb BMM and use Triton's default (`models/deepseek_common/attention_forward_methods/forward_mla_rocm.py`) | GLM-5.2 prefill. `_absorb_bmm_config` (`:156`) trips an LLVM assertion in Triton 3.7.0 on gfx950, the Triton this image ships; reproduced on 10-27 |

Not patched, by reading the same source: the DSA page-table rows (the recipe's
`index_share_for_mtp_iteration: false` keeps page-table and top-k rows equal), the non-final-chunk KV
wait event (only the overlap-scheduler path differs; PP prefill runs `--disable-overlap-schedule`),
and HiCache staged write-back on ROCm (the controller moves backup indices per pool on this source).

Nothing else in the image changes: Infera is installed with `--no-deps` at the master's router
version, and `infera.engine.sglang` starts SGLang's own `launch_server` unmodified.

## Why the unmodified upstream image cannot run this benchmark

- B7: the TP1 × PP4 prefill does not load — PP rank 1 dies with
  `AttributeError: 'PPMissingLayer' object has no attribute 'embedding_dim'`.
- B1, B2: the DP-attention decode either fails in the indexer (`Expected lengths.size(0) == B`) or
  hangs with every DP rank stopped, as soon as ranks carry unequal batches.
- B6: under the AgentX load the prefill scheduler blocks on the metrics socket (py-spy capture of a
  wedged GLM-5.2 prefill, 2026-10-09) and the point fails on stalled requests.
- B8: the first long prefill aborts in Triton's LLVM backend.

## Removal plan

Each fix goes when a pinned ROCm SGLang nightly contains it: drop its file and its line in
`apply.sh` in the PR that bumps the `image:` of `glm5.2-fp4-mi355x-infera-sglang-agentic-disagg`.
When the last one is gone, delete `infera-sglang-patches/`, the patch step in `infera-sglang.sh` and
this waiver in the same PR.
