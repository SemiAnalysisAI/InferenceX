# Inference-engine patch waiver: PR #3217

## Scope and reason

This AgentX-only draft experiment covers
`dsv41flash-fp4-mi355x-vllm-agentic-dspark-tp2-engram-cpu`, pinned to
`vllm/vllm-openai-rocm:nightly-af1c01499b289be555c475669ba50a88e96d846e`.
The stock image rejects explicit Engram configuration on ROCm, and its AMD
model falls through to the base `Engram`, so the embedding tables stay on the
GPU. It cannot execute the requested `--engram-config '{"cpu_offload":true}'`
experiment unmodified.

## What changes

The [patch entrypoint](../../utils/patches/dsv41flash_rocm_engram/apply.sh)
applies the checked-in [engine diff](../../utils/patches/dsv41flash_rocm_engram/rocm-engram-cpu.patch)
only for TP2. It verifies the image tag and patch applicability before use.

The diff is the runtime part of upstream
[vllm-project/vllm#57491](https://github.com/vllm-project/vllm/pull/57491):

- Widen the `is_cuda()` gates in `vllm/config/engram.py` and
  `vllm/config/vllm.py` to `is_cuda_alike()`, so ROCm resolves and accepts an
  Engram configuration.
- Import the shared `Engram` from `nvidia/engram.py` in `amd/model.py`. Its
  pinned-host tables read through the existing ROCm-capable accelerator-view
  helper and prefetch on a side stream. No AMD-specific code is added.
- Hashing, TP ownership, lookup math and graph staging are the upstream code
  paths. DP head sharding and `dp_shared_memory` arrive with the import but are
  inert at `data_parallel_size=1`. The stock InferenceX TP4 recipe is unpatched.
- The upstream test-file hunk is not shipped; the image has no test tree.

Every patched GPU job must pass `rocm_preflight.py` before loading the model.
It checks the widened gate, the shared `Engram` import, host/HBM lookup
equivalence, TP2 shard reconstruction, changed-ID graph replay, constructor
configuration, and storage replacement. A GPU-less environment fails the
preflight rather than passing on skipped tests. The patch checksum and
preflight results are saved as CI log artifacts.

## Upstream status and review gate

The patch is [vllm-project/vllm#57491](https://github.com/vllm-project/vllm/pull/57491),
open upstream at the time of writing and not yet merged or released. Model
support context: [vllm-project/vllm#56214](https://github.com/vllm-project/vllm/pull/56214).
A human must review the hardware evidence here alongside the upstream review.
The upstream-publication merge gate remains outstanding until #57491 merges.
This waiver records the experiment; it does not authorize merging or bypassing
CODEOWNER review.

## Validation and removal

Local recipe behavior tests and CPU configuration validation pass; the patch
applies to the pinned upstream revision with `git apply --check`. Hardware
preflight, the complete AgentX throughput grid, and the c32 evaluation remain
required. Do not treat matrix generation, CPU tests, or a queued workflow as
GPU validation.

Remove the patch, preflight entrypoint invocation, and waiver when a pinned
upstream ROCm image ships #57491. Re-run the full TP2 AgentX grid with
evaluation on that unmodified image before merge. Fixed-sequence and 8k1k
benchmarks are outside this experiment's scope.
