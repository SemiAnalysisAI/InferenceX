# Inference-engine patch waiver: PR #3217

## Scope and reason

This draft experiment covers `dsv41flash-fp4-mi355x-vllm-agentic-dspark-tp2-engram-cpu`
and `dsv41flash-fp4-mi355x-vllm-mtp-tp2-engram-cpu`, both pinned to
`vllm/vllm-openai-rocm:nightly-af1c01499b289be555c475669ba50a88e96d846e`.
The stock image rejects explicit Engram configuration on ROCm, and its AMD
implementation allocates the embedding tables on the GPU. It cannot execute
the requested `--engram-config '{"cpu_offload":true}'` experiment unmodified.

## What changes

The [patch entrypoint](../../utils/patches/dsv41flash_rocm_engram/apply.sh)
applies the checked-in [engine diff](../../utils/patches/dsv41flash_rocm_engram/rocm-engram-cpu.patch)
only for TP2. It verifies the image tag and patch applicability before use.

- Allow explicit TP-only Engram settings for DeepSeek V4.1 on ROCm.
- Allocate Engram weights and E8M0 scales in pinned host memory and use the
  existing ROCm-capable accelerator-view helper for lookup.
- Retain common hashing, TP ownership, lookup math, and graph staging.
- Reject Engram DP sharding and shared memory. Preserve the omitted-config
  AMD HBM default and the stock InferenceX TP4 recipe.

Every patched GPU job must pass `rocm_preflight.py` before loading the model.
It checks host/HBM lookup equivalence, TP2 shard reconstruction, changed-ID
graph replay, constructor configuration, and storage replacement. A GPU-less
environment fails the preflight rather than passing on skipped tests.
The patch checksum and preflight results are saved as CI log artifacts.

## Upstream status and review gate

Model-support context: [vllm-project/vllm#56214](https://github.com/vllm-project/vllm/pull/56214).
That PR is not a submission of this offload patch. No dedicated upstream PR
has been submitted, reviewed, or merged. A human must review this patch and
the hardware evidence before submitting it under vLLM's contribution policy.
The upstream-publication merge gate remains outstanding. This waiver records
the experiment; it does not authorize merging or bypassing CODEOWNER review.

## Validation and removal

Local recipe behavior tests and CPU configuration validation pass; the patch
applies to the pinned upstream revision. Hardware preflight, both complete
throughput grids, and both c32 evaluations remain required. Do not treat
matrix generation, CPU tests, or a queued workflow as GPU validation.

Remove the patch, preflight entrypoint invocation, and waiver when a pinned
upstream ROCm image ships equivalent reviewed support. Re-run the full TP2
AgentX and 8k1k grids with evaluations on that unmodified image before merge.
