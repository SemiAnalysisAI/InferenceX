# Serving-stack patch waiver — PR #2596

Filed per [`docs/PR_REVIEW_CHECKLIST.md`](../PR_REVIEW_CHECKLIST.md): the B300
launcher adjusts the checked-out srt-slurm source before submitting this
configuration, which requires a documented waiver.

## Scope statement

This waiver covers only the conditional srt-slurm root-remap adjustment in
[`runners/launch_b300-dsxe.sh`](../../runners/launch_b300-dsxe.sh) for
`dsv4` FP4 `dynamo-trt` jobs. It does not modify the TensorRT-LLM container or
model files.

## What is patched

After checking out the launcher's pinned srt-slurm release, the launcher changes
`CONTAINER_REMAP_ROOT_EXPORT` in `src/srtctl/core/slurm.py` from
`ENROOT_REMAP_ROOT=yes` to `ENROOT_REMAP_ROOT=no`. Exact pre- and post-change
matching makes the adjustment fail closed if the pinned srt-slurm source changes.

## Why the unmodified upstream cannot run this benchmark

The recipes install Dynamo and launch TensorRT-LLM workers through host PMIx.
srt-slurm normally injects `ENROOT_REMAP_ROOT=yes` into Dynamo-install worker and
frontend `srun` steps. For this TensorRT-LLM MPI path, remapping the container user
to root prevents the workers from using the host PMIx socket under the expected
runner identity. Disabling that remap preserves the host MPI/PMIx contract while
leaving the pinned serving container unchanged.

## Upstream status

- [`NVIDIA/srt-slurm#234`](https://github.com/NVIDIA/srt-slurm/pull/234)
  introduced the Dynamo-install `ENROOT_REMAP_ROOT=yes` injection.
- [`NVIDIA/srt-slurm#304`](https://github.com/NVIDIA/srt-slurm/pull/304)
  is the open container-baking follow-up intended to remove cold Dynamo dependency
  installation from runtime startup.

## Removal plan

Remove this substitution and this waiver when srt-slurm provides a supported
per-recipe or per-backend root-remap control for TensorRT-LLM MPI workers, or when
the selected image and srt-slurm path no longer require runtime Dynamo installation.
At that point, validate the unchanged upstream srt-slurm release on the B300 DSXE
launcher before deleting the exception.
